# ByteLang

## Introduction
This is a small Esoteric language made in C++.
It has 4 symbols, '+', '-', '*', and '.', each of these have a different work
The language works on a single byte of memory, which ranges from 0 to 255.

## Guide
To Increase the value of the byte, use '+'
To decrease the value of the byte, use '-'
To clear the byte, use '*'
To print the byte's ASCII value, use *

#### Note:
The byte will go back to o from 255 if increase further
And will go from 0 t 255 if decreased below.

## Examples:
This repository has 4 examples, each of them does a different work
hello.bl will print HELLO WORLD for you
alphabet.bl will print some Alphabets for you
number.bl will print numbers from 0 to 9
And invalid.bl is for demonstrating its error handling

### Note:
The interpreter will stop the moment it will see error, so use it carefully
